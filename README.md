## 🎮 Xplore – Game Promotional Website

**Live Demo:** [Click Here](https://xplore-site.netlify.app/)

**Tech Stack:** React, TypeScript, Vite, GSAP, Tailwind CSS

---

### 🧠 Overview

**Xplore** is a modern, fully responsive **game promotional website** built to deliver a smooth, immersive browsing experience.
It focuses on **motion design**, **pixel-perfect UI**, and **optimized performance**, inspired by professional product marketing sites.

---

### 🚀 Features

* ✨ **Advanced GSAP animations** and transitions for interactive user experience
* 📱 **Responsive design** across all devices and screen sizes
* 🧩 **Reusable React components** for modular and scalable UI
* ⚡ **Fast build performance** using Vite bundler and optimized asset handling
* 🎨 **Modern, clean layout** built with Tailwind CSS

---

### 🛠️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/EvansAbraham/xplore.git
cd xplore-game-site

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```
